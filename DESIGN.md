# Design System: Cinnabar

## Overview

**Creative North Star: "The Game, Played Straight"**

A game client's site that opens on the game itself. The owner chose the category standard over four themed worlds, so there is no decorated concept to lean on: a warm near-black ground, real in-game captures, the textured logotype, and one red. Clarity carries the page, and craft has to carry the clarity, in the grading of the captures, the tightness of the type and the finish of every pressed state.

The game supplies all the spectacle. Captures run full-bleed or hang off the page edge, and the interface sits quietly on or beside them in a single grotesk with thin warm hairlines and restrained corners. Density rises with the surface's job: the home page is spacious and persuasive, the mod page is a generous catalog, and the book is a tighter reading tool that shares the same ground, header and accent.

Decoration is the confirmed rejection. Interface chrome does not borrow game textures, pixel type or a themed world; the game enters through captures and the logotype.

**Key Characteristics:**
- Warm near-black ground, with tonal steps rather than cool greys
- Owner's captures of Cinnabar as the only imagery, graded warm rather than darkened
- One typeface for all text, with a mono voice for machine-readable values
- One solid red, reserved for download actions, plus quieter tints that signal
- Soft, negative-spread shadows, and a 1px press on tactile controls

## Colors

A warm, slightly brown-black neutral range carrying a single red family drawn from the Cinnabar icon.

### Primary
- **Cinnabar Red** (#B8281E): The solid fill of the download actions on the home and mod pages. The value is the icon's body fill, read at render time from the client repository's icon, never set as a website constant.
- **Lit Cinnabar** (icon red mixed 10% toward white): Hover on the download actions.
- **Pressed Cinnabar** (icon red mixed 22% toward black): Pressed download actions, text selection and search-result marks.

### Secondary
- **Signal Red** (icon red mixed 26% toward #ffb199): Red as a thin mark: the player chart line and point stroke, the current-page underline in the header, the checked channel radio, and the small active marker in the docs sidebar.
- **Ember Text** (icon red mixed 56% toward #ffb199): Red as readable text or icon: docs links, docs syntax keywords, docs warning callouts, footnote highlights, the risk notice's warning icon, and the input caret.

### Neutral
- **Warm Ground** (#141312): The page, the book, the solid header, and inset fields inside dialogs. Also matches the browser theme color.
- **Raise** (#1d1b1a): The first tonal step: menus, dialogs, code blocks, callouts, table headers, the range tray.
- **Raise Two** (#292624): Hover and active fills on top of Raise.
- **Hairline** (#322f2c): Default dividers, chart gridlines and resting borders.
- **Strong Hairline** (#4d4843): Borders of floating surfaces and fields, column-head rules, the selected range segment.
- **Warm Ink** (#f6f3ef): Headlines, primary text, live figures, and the inverted copy button.
- **Soft Ink** (#d2cdc7): Supporting text, resting nav, leads and captions.
- **Quiet Ink** (#aaa49d): Footer and meta text, chart axis labels, catalog counts, secondary hints.
- **Focus White** (#ffffff): The focus ring on every interactive element.
- **On Red** (#ffffff): Text and icons on the download actions and marks.
- **Reading Ink** (#ece8e2) and **Code Ink** (#e6e1da): Slightly softened body and code text in the book, for long reading on the dark ground.
- **Syntax set** (comment #a39d96, string #dcc9a3, number #efb7a4, type #c9c3bb): Warm, low-chroma docs highlighting, so code stays in the world and keywords are the only red.
- **Veils and washes** (#1413128c, #1d1b1af0, #0b0a09c7, #ffffff1a, #ffffff0f, #ffffff33): Translucent versions for surfaces over captures, the modal backdrop, nav hover and press, and hairlines on imagery.
- **Resting underlines** (#ffffff59, Ember Text at 35%): Link underlines at rest, which rise to full color on hover.

### Named Rules

**The One Action Red Rule.** Cinnabar Red as a solid fill belongs to the download actions and nothing else; the install field's selected-text highlight is its only other use. If a second control on a screen is solid red, it is wrong.

**The Red Signals Rule.** Outside the download actions, red appears as a thin line or as small text and icons, marking state, live data, risk, or the book's links and keywords. It does not fill surfaces, and home and mod links stay ink with a pale underline.

**The Icon Is The Source Rule.** The brand red is read from the client repository's icon. Never hardcode it into a page.

## Typography

**Display Font:** Schibsted Grotesk (with system-ui, sans-serif)
**Body Font:** Schibsted Grotesk (with system-ui, sans-serif)
**Label/Mono Font:** JetBrains Mono (with ui-monospace, monospace)

**Character:** A sturdy, slightly editorial grotesk set tight at large sizes and plain at small ones, which stays out of the way of the game imagery. The mono is a working voice for values a machine would produce.

Fonts are self-hosted: the grotesk at 400, 500 and 700, the mono at 400 and 500.

### Hierarchy
- **Display** (700, up to 56px, 1): The word "Mod" beside the logotype in the mod page title. The logotype image is the display object on every page.
- **Headline** (700, up to 38px, 1.08 to 1.14): Tagline, closing line, mod section heads, chart head and docs page title, each with its own clamp in the frontmatter, tracked between -0.028em and -0.035em.
- **Title** (700, 20px to 28px, 1.18 to 1.3): Dialog heads, catalog and step heads, fact heads, docs section heads, tracked -0.012em to -0.022em.
- **Lead and live figure** (500, up to 28px, 1.28 to 1.3): The mod page's description and the current online count. Supporting leads use 400 at up to 20px and 1.5.
- **Body** (400, 17px, 1.6): Default text. The book uses the same size at 1.68 in a 64ch column.
- **Small body, caption, meta** (400, 16px, 15px, 14px, about 1.5): Secondary copy, figure captions and the risk notice, footers and hints.
- **Action and label** (700 at 18px for download actions; 500 at 15px to 16px for other controls): Controls never use all caps or wide tracking.
- **Code and data** (mono 400, 12px to 14px): Commands, code, keycaps, chart axis numerals and catalog counts, with tabular numerals where figures stack.

### Named Rules

**The One Voice Rule.** Schibsted Grotesk sets all prose, headlines and controls. The textured logotype image is the only other display object.

**The Machine Values Rule.** JetBrains Mono is for commands, code, keys, chart axes and small catalog counters. Headline figures such as the online count and download total stay in the grotesk.

**The Tighten With Size Rule.** Tracking is neutral at body sizes and tightens as type grows, down to -0.04em at display.

## Layout

A centred page of up to 1360px inside a fluid gutter (16px to 64px), under a 64px header. Sizes use px throughout the shared styles because the book's root is 10px.

Captures and type stop growing on large displays: the home capture renders at 125% of the window width or 186% of its height, whichever is larger, and headlines cap well below their old sizes, so a 2560px screen shows more of the world, not a bigger page. The home page opens with a capture filling the full small viewport: logotype, tagline, edition line, split download and download count are centred in the free space, and the risk notice is pinned to the bottom edge of the opening. A live-data section, gallery and full-bleed closing capture follow. The mod page opens differently, with a two-column head on the plain ground, the logotype and "Mod" beside the summary and download, followed by a framed capture capped at 1120px so it never upscales on a large display; its catalog and layout heads repeat the same 7:5 split. The book is a fixed 288px sidebar and a 64ch reading column.

Vertical rhythm is even: 88px to 96px between major sections, falling to 80px at 900px and under, with 72px between gallery rows. Inside sections, spacing steps through 8, 12, 16, 24, 32, 40, 56 and 64px.

The gallery sits on a 12-column grid (6 columns at 900px and under). Images hang from different columns, and the outer ones bleed off the page edge, losing their outer corners as they do. The mod catalog runs four columns, then two, then one; list rows are separated by hairlines rather than boxed.

The shared breakpoints are 900px (layouts stack) and 480px (phone adjustments and full-width download). The mod page's menu capture overscales at 700px and under. The book adds 1079px (sidebar becomes a drawer), 1000px (search toggle becomes a field) and 700px.

**The Capture Bleeds Rule.** Primary captures run to the viewport edge rather than sitting framed in the column; framed screenshots are for reference shots beside explanatory text.

## Elevation & Depth

A hybrid of tonal layering and soft shadow. Surfaces on the ground step up through Raise and Raise Two, with hairline borders providing most of the definition. Shadows are reserved for what truly floats: the download action, menus, dialogs, the risk notice over its capture, the docs drawer, and framed screenshots on hover. The opening has its own depth from the capture: a warm multiply grade, ground-colored scrims at the edges, a soft warm pool behind the text, and drop shadows on the logotype and on text set over imagery.

### Shadow Vocabulary
- **Action lift** (`box-shadow: inset 0 1px #ffffff2e, 0 12px 28px -12px #000c`): Resting download action; the top inner light gives the button its face.
- **Split lift** (`box-shadow: 0 16px 36px -14px #000e`): Around the split download group.
- **Action press** (`box-shadow: inset 0 1px #0000004d`): Pressed download action; the light flips to shade.
- **Notice** (`box-shadow: 0 16px 36px -18px #000c`): The risk notice over its capture.
- **Menu** (`box-shadow: 0 20px 48px -12px #000d`): The channel menu.
- **Dialog** (`box-shadow: 0 32px 80px -24px #000`): Install dialogs.
- **Shot hover** (`box-shadow: 0 24px 48px -28px #000`): Framed screenshots on hover, with a 2px lift.
- **Drawer** (`box-shadow: 24px 0 48px -24px #000c`): The docs sidebar as a drawer.
- **Keycap** (`box-shadow: inset 0 -1px #0006`): The bottom edge of a keyboard key.

### Named Rules

**The Negative Spread Rule.** Every outer box shadow pulls in with a negative spread and a long blur, so it reads as light falling away beneath the surface, not as a halo or a hard edge.

**The Warm Grade Rule.** A capture is graded with a warm multiply tone so its sky stays a dusk color, with ground-colored scrims only where text or the page edge needs them. A flat dark overlay across the whole image turns it grey.

## Shapes

Restrained, gently rounded rectangles that scale with the object: 5px for keys and inline code, 6px for docs list items and small buttons, 8px for navigation and form controls, 10px for download actions and book blocks, 12px for menus, notices and screenshots, 16px for dialogs. Borders are 1px hairlines; the 2px current-page underline and 2px focus ring are the heaviest lines in the system. Small markers are near-square rather than round (the online-count marker and docs active marker), and the only true circles are the channel radios. Images that bleed off an edge lose their rounded corners on that side.

## Components

### Buttons
Tactile and confident on the one primary action, quiet everywhere else.

- **Shape:** Softly rounded (10px) on primary; 8px on secondary controls.
- **Primary:** Solid Cinnabar Red with white 700 text at 16px, 52px tall with 24px side padding and a filled download icon. On the home page it is a split button: the action plus a 56px channel toggle, divided by a dark hairline.
- **Hover / Focus:** Hover lightens the fill; press darkens it, flips the top light to shade and drops 1px. Color changes take .15s ease-out, the press .1s ease-out. Focus is a 2px white ring at 3px offset.
- **Copy:** An inverted ink button with ground text (48px) beside the command field, turning pure white on hover.
- **Icon close:** A transparent 44px square that gains Raise Two on hover.

### Channel Menu
- **Style:** A Raise panel (12px) with a strong hairline and the menu shadow, 8px under the split button. The trigger's chevron turns 180 degrees over .18s.
- **Options:** 56px rows with a name and a quiet hint. A hollow radio ring on the left fills with Signal Red when checked, inset with a ring of Raise.
- **State:** Hover and keyboard focus fill with Raise Two; the focus ring sits inside the row.

### Range Control
- **Style:** A Raise tray (10px, 4px padding) holding 44px text segments in Soft Ink, for the player chart's time ranges.
- **State:** The selected segment fills with Strong Hairline in Warm Ink. Selection is not red.

### Links Over and Under Captures
- **Platform link:** A 44px, 8px-radius link on a translucent ground veil with a white-alpha hairline, used for direct downloads over the closing capture. Hover turns it solid Raise Two.
- **Download option:** A 52px dialog row with a strong hairline, a label and a quiet download icon at the end. Hover fills with Raise Two and brightens the icon.
- **Text link:** Ink with a pale 1px underline at 4px offset, rising to full color on hover. In the book, links are Ember Text with a tinted underline at 3px offset.

### Inputs / Fields
- **Command field:** 48px on Warm Ground, with a strong hairline, 8px radius and 14px mono text.
- **Docs search:** At wide widths the toggle is drawn as a Raise field with a "Search" label and a small "/" key. The full search field is 52px with a 10px radius.
- **Focus:** The same 2px white ring.

### Navigation
- **Style:** A 64px header with the mark and bold wordmark on the left and 15px weight-500 links on the right, with GitHub and Discord as 44px icon buttons. At 480px and under the wordmark hides and padding tightens.
- **States:** Hover adds a 10% white wash, press a 6% wash and a 1px drop. The current page takes Warm Ink and a 2px Signal Red underline.
- **Scroll behavior:** On home and mod it floats transparent over the opening, then turns solid with a hairline over the final 96px of a scroll-linked range. Browsers without scroll timelines get the solid state from the start. In the book it is always solid.

### Dialog
- **Style:** Up to 560px on Raise (16px) with a strong hairline, 32px padding and the dialog shadow, over a dark warm backdrop. It rises 8px while fading in over .22s, and only when motion is welcome.

### Risk Notice
A signature component. A wide bar (up to 880px, 12px radius) with a nearly opaque Raise fill, a white-alpha hairline and a 20px Ember Text warning icon, pinned to the bottom of the home opening so the risk is read beside the download.

### Live Chart
A signature component. A thin Signal Red line (1.75px) over hairline gridlines, with mono tabular axis labels in Quiet Ink, an ink point with a red stroke, and a soft-ink cursor. Live counts above it are ink text with a small near-square ink marker. Empty live values stay hidden while holding their layout space; a missing chart shows a plain message between two hairlines.

### Screenshot Frame
A clickable capture with a 1px hairline and 12px radius on Raise. Hover strengthens the border, lifts it 2px and adds the shot-hover shadow; press settles it.

### Numbered Steps
A single Raise panel (three columns divided by hairlines, stacking at 900px) for real sequential instructions, each led by a large ink numeral in tabular figures. The numeral is the only ornament.

### Docs Blocks
Code blocks, callouts and table wrappers share one treatment: Raise fill or Raise header, 1px hairline, 10px radius. Inline code and keycaps are small Raise chips with 5px corners. The active chapter fills with Raise Two and carries a 6px near-square Signal Red marker. Previous and next links are 64px outlined rows.

### Motion
Under reduced motion, transitions and press or hover lifts stop on every page. State changes run .12s to .15s ease-out; transforms on press run .1s. Entrances and the shot lift use `cubic-bezier(.16, 1, .3, 1)` over .18s to .22s. The hero capture's drift and the mod capture's settle are scroll-linked, and both are removed under reduced motion.

## Do's and Don'ts

### Do:
- **Do** keep Cinnabar Red as a solid fill on the download action alone, and read its value from the client's icon.
- **Do** use the owner's captures of Cinnabar as the imagery, and let primary captures run to the viewport edge.
- **Do** grade captures with a warm multiply tone, adding ground-colored scrims and text shadows only where legibility needs them.
- **Do** set all prose, headlines and controls in Schibsted Grotesk, tightening tracking as size grows.
- **Do** use JetBrains Mono for commands, code, keys, chart axes and small counters, with tabular figures where values stack.
- **Do** define surfaces by tonal steps and 1px warm hairlines, using white-alpha hairlines only on top of imagery.
- **Do** give every interactive element the 2px white focus ring.
- **Do** give controls on home, mod and the shared header 44px targets, and let dense docs lists grow to that size on coarse pointers.
- **Do** make tactile controls press down by 1px, and keep any larger motion behind a reduced-motion check.
- **Do** keep the risk notice prominent beside the download, marked with Ember Text.

### Don't:
- **Don't** fill surfaces, section backgrounds or secondary buttons with red, or color home and mod text links red.
- **Don't** darken a whole capture with a flat black or grey overlay.
- **Don't** add a third typeface, or decorate chrome with pixel type or game textures; the game arrives through captures and the logotype.
- **Don't** use cool greys or pure black surfaces; the neutrals stay warm.
- **Don't** use bright white text as the default body color; Warm Ink, Soft Ink and Quiet Ink carry the hierarchy, and pure white is for focus and text on red.
- **Don't** use an outer box shadow without negative spread, or add one to a surface that is not floating.
- **Don't** simulate live figures; empty values look empty.
